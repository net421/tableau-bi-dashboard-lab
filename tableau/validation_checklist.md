# Tableau Validation Checklist

- Headline KPIs match `executive_kpis.csv`.
- OTIF does not exceed on-time or complete-order rate.
- Unit fill rate uses ratio of sums.
- Freight cost per kg uses weighted aggregation.
- Filters do not create duplicated order counts.
- LOD expressions are documented.
- Table calculation partitioning is explicitly configured.
- Tooltips include definition, owner, and refresh date.
- Dashboard filters behave consistently across sheets.
- Screenshots are updated after metric-definition changes.
